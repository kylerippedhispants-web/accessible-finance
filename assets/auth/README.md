# Google sign-in button

`google-signin-light.svg` is Google's unmodified, pre-approved light pill button
for Android and Web, downloaded October 29, 2026 from:

- https://developers.google.com/identity/branding-guidelines
- https://developers.google.com/static/identity/images/signin-assets.zip

Archive entry: `Android + Web/SVG/Light/Theme=Light, Show text=Yes, Shape=Pill, Platform=Android+Web.svg`.

The supplied SVG contains outlined lettering, so the button needs no additional
font download or third-party browser script. Preserve its aspect ratio, colours,
and wording. The surrounding HTML button provides the accessible name and a
minimum 44px touch target; the SVG itself is decorative for assistive technology.
